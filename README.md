# 🧶 فروشگاه تعاونی صنایع‌دستی نساجی

> یک فروشگاه آنلاین کامل برای **شرکت تعاونی صنایع‌دستی نساجی** — شامل تمام بخش‌های عمومی (فروشگاه) و مدیریتی (پنل).
> ساخته‌شده با **PHP ۸.۳ خالص، بدون هیچ وابستگی خارجی** (بدون Composer، بدون vendor، بدون فریمورک) بر پایه مهارت [`andrbi102/php-zero-dep`](https://github.com/andrbi102/php-zero-dep).
>
> فلسفه: **«بازآفرینی آگاهانه چرخ»** — اتولودر، روتر، DI، CSRF، نشست و لایه داده همه دست‌نویس و خودکفا هستند.

---

## ✨ امکانات

### بخش‌های عمومی (فروشگاه)
- صفحه اصلی با محصولات منتخب و جدیدترین تولیدات
- کاتالوگ محصولات با فیلتر دسته، جستجو، مرتب‌سازی و صفحه‌بندی
- صفحه جزئیات محصول + محصولات مرتبط + معرفی سازنده
- سبد خرید مبتنی بر نشست (افزودن/ویرایش/حذف)
- تسویحه حساب با نشانی تحویل و کد تخفیف
- ثبت‌نام/ورود/خروج مشتری (Argon2id)
- حساب کاربری: سفارش‌های من، جزئیات سفارش، ویرایش پروفایل، تغییر رمز
- صفحه نساجان تعاونی + پروفایل هر عضو و محصولاتش
- درباره تعاونی، تماس با ما (با ذخیره پیام)

### بخش‌های مدیریتی (پنل `/admin`)
- **داشبورد**: KPIها، نمودار فروش ۷ روزه، سفارش‌های اخیر، موجودی پایین
- **مدیریت محصولات**: ایجاد/ویرایش/بایگانی، تنظیم سریع موجودی، قیمت و مزد نساجی
- **دسته‌بندی‌ها**: سلسله‌مراتبی با slug
- **سفارش‌ها**: فهرست با فیلتر وضعیت، جزئیات، تغییر وضعیت، تحویل نهایی
- **مشتریان**: فهرست و پروفایل با سفارش‌ها
- **نساجان تعاونی**: پروفایل عضو، محصولات، وضعیت مالی، تسویه‌ها
- **تسویه مالی** (نقش حسابدار/مدیرکل): فهرست تسویه‌های معلق و تأیید پرداخت
- **کدهای تخفیف**: درصدی/ثابت، حداقل خرید، سقف استفاده، انقضا
- **گزارش‌ها**: فروش (پرفروش‌ترین + بر اساس وضعیت)، موجودی، عملکرد اعضا
- **پیام‌های تماس** و **تنظیمات** فروشگاه

### ویژگی‌های تعاونی
- هر محصول به یک **عضو تعاونی (نساج)** نسبت داده می‌شود.
- مبلغ **cost** در محصول = مزد نساجی (برای تسویه).
- هنگام **تحویل سفارش**، به‌ازای هر قلم، تسویه‌ای با وضعیت `pending` و مبلغ `cost × quantity` ساخته می‌شود.
- حسابدار تسویه را `paid` می‌کند؛ گزارش عملکرد اعضا مجموع تسویه معلق/پرداخت‌شده و سهام را نشان می‌دهد.

## 🔒 امنیت (OWASP‌محور)

رعایت‌شده طبق SPEC مهارت `php-zero-dep`:

| قید | وضعیت |
|-----|-------|
| بدون Composer / بدون vendor | ✅ |
| `declare(strict_types=1)` + PHPDoc در همه فایل‌ها | ✅ |
| همه کوئری‌ها **PDO Prepared Statement** (هیچ `SELECT *`) | ✅ |
| همه خروجی‌ها `htmlspecialchars(ENT_QUOTES, UTF-8)` | ✅ |
| کوکی نشست **HttpOnly + Secure + SameSite=Strict** | ✅ |
| **CSRF** امضاشده HMAC + مقایسه زمان‌ثابت (`hash_equals`) | ✅ |
| رمز عبور **Argon2id** + `password_needs_rehash` (مهاجرت تدریجی) | ✅ |
| هدرهای امنیتی: CSP، HSTS، X-Content-Type-Options، X-Frame-Options، Referrer-Policy | ✅ |
| بدون توابع ممنوع (`eval`, `exec`, `system`, …) | ✅ |
| کاهش atomic موجودی با شرط `stock >= qty` (جلوگیری از race) | ✅ |
| snapshot اقلام سفارش (قیمت/هزینه/نام/عضو) — مستقل از تغییر后来的 محصول | ✅ |

بررسی: `php tests/security-audit.php` و `python3 scripts/audit.py`.

## 🚀 نصب و راه‌اندازی

### پیش‌نیاز
- PHP **۸.۳+** با افزونه‌های: `pdo`, `pdo_sqlite` (یا `pdo_mysql`)، `mbstring`، `sodium` (اختیاری، فقط برای رمزنگاری میدانی).

> نسخه ۸.۲ تا پایان ۲۰۲۶ EOL است؛ توصیه ۸.۳ یا بالاتر.

### گام ۱ — استقرار روی هاست با SSH / لوکال
```bash
git clone https://github.com/andrbi102/handicraft-coop-ecommerce.git
cd handicraft-coop-ecommerce

# مهاجرت دیتابیس
php scripts/migrate.php

# داده‌های اولیه (مدیرکل، اعضا، محصولات، تنظیمات)
php scripts/seed.php
```

### گام ۲ — اجرای لوکال با built-in server
```bash
php -S localhost:8000 server.php
# سپس: http://localhost:8000
```

### گام ۳ — هاست اشتراکی بدون SSH (FTP فقط)
1. کل پروژه را آپلود کنید؛ **document root را روی پوشه `public/` تنظیم کنید** (یا در صورت نبود، محتوای `public/` را در public_html و بقیه پوشه‌ها یک سطح بالاتر قرار دهید).
2. یک متغیر محیطی `MIGRATE_TOKEN` با یک رشته تصادفی طولانی بسازید (در `.htaccess` با `SetEnv` یا در پنل هاست).
3. آدرس `https://your-domain/migrate.php?token=<MIGRATE_TOKEN>&seed=1` را باز کنید.
4. **سپس فایل `public/migrate.php` را حذف کنید** یا توکن را تغییر دهید.

### گام ۴ — ورود به پنل مدیریت
پس از seed:
| نقش | ایمیل | رمز |
|-----|-------|-----|
| مدیر کل | `admin@coop.local` | `admin123456` |
| مدیر فروش | `manager@coop.local` | `manager123456` |
| حسابدار | `accountant@coop.local` | `accountant123456` |
| مشتری | `customer@coop.local` | `customer123456` |

> ⚠ این رمزها **فقط برای دمو** هستند. پس از نصب، رمز مدیرکل را تغییر دهید یا کاربران دمو را حذف کنید.

```
handicraft-coop-ecommerce/
├── public/                  # نقطه ورود (document root)
│   ├── index.php            # کنترلر فرانت
│   ├── migrate.php          # اجرای مهاجرت از مرورگر (محافظت‌شده با توکن)
│   ├── .htaccess            # بازنویسی Apache
│   └── assets/              # CSS/JS/تصاویر (استاتیک)
├── src/
│   ├── Core/                # بوت‌استرپ، Config، Auth، Middleware، Money، Slug، PersianDate
│   ├── Models/              # دسترسی داده (PDO Prepared)
│   ├── Services/            # منطق کسب‌وکار (Cart، Order، Settlement)
│   ├── Controllers/         # Storefront + Admin
│   └── Support/             # scaffolds کپی‌شده + Cards helper
├── templates/               # قالب‌های PHP با escape خودکار
│   ├── layouts/             # store.php / admin.php
│   ├── storefront/          # صفحات عمومی
│   └── admin/               # صفحات پنل
├── migrations/              # 001_create_tables.sql
├── routes/web.php           # نقشه مسیرها
├── scripts/                 # migrate.php, seed.php, audit.py
├── tests/                   # smoke-test.php, security-audit.php
├── storage/                 # db, logs, uploads (در .gitignore)
├── config/app.php
└── server.php               # روتر dev server
```

## ⚙️ پیکربندی

`config/app.php` و متغیرهای محیطی:

| کلید | توضیح | پیش‌فرض |
|------|-------|---------|
| `COOP_DB_DSN` | DSN پایگاه داده | `sqlite:storage/db/coop.sqlite` |
| `COOP_DB_USER` / `COOP_DB_PASS` | کاربر/رمز MySQL | خالی |
| `COOP_DEBUG` | `1` = حالت اشکال‌زدایی | خاموش |
| `APP_KEY` | کلید امضای CSRF (اگر نباشد، خودکار تولید و در `storage/db/app_key.txt` ذخیره می‌شود) | خودکار |
| `MIGRATE_TOKEN` | توکن endpoint مهاجرت وب | — |

برای **MySQL**: `COOP_DB_DSN=mysql:host=127.0.0.1;dbname=coop;charset=utf8mb4` را تنظیم کنید. توجه: `SettingModel` و `Migrator` از قواعد SQLite بهینه‌اند؛ برای MySQL ممکن است نیاز به تطبیق جزئی `ON CONFLICT` → `ON DUPLICATE KEY UPDATE` باشد.

## 📦 محدودیت‌ها (صادقانه)

- **بدون درگاه پرداخت آنلاین**: پرداخت به‌صورت کارت‌به‌کارت/در محل پیش‌بینی شده؛ اتصال درگاه نیازمند مستندات رسمی API است (طبق قید MCP مهارت، بدون مشورت مستندات، کد درگاه تولید نمی‌شود).
- **بدون آپلود تصویر از پنل**: تصاویر محصولات به‌صورت دستی در `public/assets/img/` قرار می‌گیرند و نام فایل در فیلد `image` محصول ثبت می‌شود. (پیاده‌سازی آپلود امن با اعتبارسنجی MIME نیاز به ADR جداگانه دارد.)
- **سبد خرید مبتنی بر نشست**: برای سادگی و مناسب هاست اشتراکی. اگر نشست کاربر از بین برود (مرورگر بسته/HTTP محلی)، سبد مهمان پاک می‌شود. نسخه پایدارتر نیاز به جدول `cart_items` دارد.
- **نشست Secure cookie**: کوکی نشست با پرچم `Secure` تنظیم می‌شود، یعنی **فقط روی HTTPS** کار می‌کند. روی HTTP محلی (تست) نشست پابرجا نمی‌ماند — برای تست لوکال از HTTPS لوکال یا ارزیابی از طریق تست `tests/smoke-test.php` استفاده کنید.
- **پشتیبان‌گیری دیتابیس**: مسئول کاربر است (SQLite = کپی فایل `storage/db/coop.sqlite`).
- **بازخوانی تاریخ شمسی**: فقط سال، با الگوریتم استاندارد محاسبه می‌شود (کافی برای فوتر).
